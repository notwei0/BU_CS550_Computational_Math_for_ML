# CS550 Computational Mathematics for Machine Learning — Boston University

Coursework from CS550 (Boston University Metropolitan College), by Wei Zhao. Each homework is a set of standalone Python scripts, one per problem.

| Folder | Topics |
|---|---|
| [`hw1`](hw1/) | Python fundamentals (loops, functions, timing) |
| [`hw2`](hw2/) | Calculus with SymPy: limits, derivatives, integrals |
| [`hw3`](hw3/) | Matrices and linear transformations, inverses |
| [`hw4`](hw4/) | Determinants, eigenvalues and eigenvectors, rotations |
| [`hw5`](hw5/) | Probability distributions, expectation and variance |
| [`hw6`](hw6/) | Optimization: gradients, eigenvalues of quadratic forms, Lagrange multipliers |

**Tools:** Python, NumPy, SymPy, SciPy, matplotlib

**Run a problem:** `python hw4/problem3.py` (install with `pip install numpy sympy scipy matplotlib`)
